# Spell Detective 🔍🦉

A spelling game for early readers. Inspector Owl shows a target word as a picture and pronounces it aloud — the child picks the correct spelling from four "suspect" cards. The wrong suspects are generated on the fly using realistic kid-error patterns, so the same word stays fresh every play.

## What it is
A single-page, no-install web app. Open `index.html` in any modern browser.

## Age
**6 – 8** (Pre-K sight words up to Grade 2 vocabulary, plus a tricky-words bonus level).

## Learning goal
- Spelling accuracy
- Phonics: noticing vowel sounds, silent letters, doubled consonants
- Sight-word recognition for the most common early-reader words

## How it works (the "AI angle")
The wrong choices aren't just random — they're generated by a rule-based "kid-error" engine that mimics how real children misspell:

| Pattern | Example |
|---|---|
| Vowel swap | `cat` → `cot` |
| Doubled letter | `friend` → `friennd` |
| Silent-e drop | `cake` → `cak` |
| Phonetic substitution | `because` → `becuz` |
| Letter reversal | `was` → `saw` |
| Dropped middle letter | `happy` → `hapy` |

When the child picks wrong, the game highlights *exactly* which letters differ between their pick and the correct spelling, plays the word again, and gives a targeted hint about that error type.

## How to play
1. Open `index.html`.
2. Tap **Start Investigation**.
3. Pick a case (level). Each case is 10 words.
4. Look at the picture, tap 🔊 to hear the word, then tap the correctly spelled suspect.
5. Solve all 10 to earn the **case file** for that level. Build a streak across cases.

## Parent dashboard ("For Grown-Ups")
From the home screen, tap **For Grown-Ups**. You'll see:
- **Mistake patterns** — which phoneme rules trip your child up the most (e.g. lots of vowel mix-ups means time to practice short-vowel families).
- **Per-word accuracy** — which words are mastered and which need more reps.

All progress is stored locally in the browser (`localStorage`). Nothing leaves the device.

## Parent tips
- Sit with younger players the first time so they know to listen to the spoken word, not just look at the emoji.
- After each level, peek at the dashboard. If "Vowel mix-ups" is high, do a few minutes of CVC practice (cat/cot/cut). If "Spell-by-sound" is high, try reading sight-word flashcards aloud.
- It's okay to replay the same case. Mastery comes from repetition.
- The audio uses your browser's built-in voice — if it sounds robotic, the on-screen text is always there as a fallback (kids can still see the picture and hear themselves say the word).

## Run instructions
No build, no server, no API keys.

```bash
# just open the file
open spell-detective/index.html        # macOS
xdg-open spell-detective/index.html    # Linux
start spell-detective/index.html       # Windows
```

Or double-click `index.html` in your file browser. Works fully offline after the first load.

## Tech
- One HTML file, inline CSS + JS, no dependencies.
- Web Speech API for word pronunciation (graceful fallback if unavailable).
- `localStorage` for progress.
- No tracking, no network calls.
