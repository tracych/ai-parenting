Drawing Telephone 🎨📞

Pass the phone. Whisper-draw. Laugh at the chain.

Who's playing?

3 to 8 players. You'll pass the device around the circle.

Rounds per player 2

Each player takes this many turns. More turns = longer game, weirder chain.

How it works

  1. Player 1 types a silly prompt (like "a panda eating spaghetti").
  2. Pass the device. Player 2 sees the prompt, then draws it.
  3. Pass again. Player 3 sees only the drawing, types what they think it is.
  4. Keep going — draw, guess, draw, guess.
  5. At the end, the Big Reveal walks through the whole chain. 🎉
