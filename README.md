# ai-parenting

A collection of small web apps and experiments built to help with parenting —
mostly things that teach, entertain, or quietly check whether a kid is actually
learning vs. just clicking around.

All single-file HTML, no build, no dependencies. Just open in a browser.

## Projects by age

### Ages 3–5 (preschool)

- 🔤 [**letter-friends**](./letter-friends/) — Alphabet + phonics through an
  alliterative silly-sentence generator with one charming character per letter.
- 🦁 [**animal-quiz-detective**](./animal-quiz-detective/) — Classic 20-questions
  game where the app guesses your animal using a decision tree — a magical first
  intro to "AI as questions and answers".

### Ages 6–8 (early elementary)

- 🦊 [**math-quest**](./math-quest/) — Math game covering **+, −, ×, ÷** across
  four themed worlds. Verifies *conceptual understanding* by asking each fact
  in multiple formats (numeric, visual, word problem) and only marking it
  "mastered" once the child has demonstrated it in at least two ways.
- 🔍 [**spell-detective**](./spell-detective/) — Spelling lineup where the wrong
  options are generated by realistic kid-error patterns (phoneme swaps, silent
  letters), with a per-phoneme parent dashboard.
- 🦉 [**code-critters**](./code-critters/) — Block-based path puzzles with a
  Socratic Hint Owl that recognizes bug patterns and asks guiding questions
  instead of giving answers.

### Ages 9–11 (upper elementary / tween)

- 🧮 [**fraction-forge**](./fraction-forge/) — Drag fraction tiles to forge
  target values; when you make a mistake, an error-classifying hint bot
  explains *why* it's wrong rather than just marking it red.
- ✨ [**cluster-quest**](./cluster-quest/) — Play k-means yourself: place
  centroids on a 2D plot of cartoon creatures and watch the algorithm
  converge. Swap the feature axes to see how "similar" depends on what you
  measure.
- 🖼️ [**real-or-render**](./real-or-render/) — Spot AI-generated images.
  Detective Mode highlights known tells *after* you commit, and calibration
  scoring penalizes overconfidence — teaching metacognition along with the
  visual skill.

### Ages 12–14 (middle school)

- 🕵️ [**hallucination-hunter**](./hallucination-hunter/) — Highlight suspicious
  spans in AI-generated paragraphs and label the hallucination type. Pre-
  annotated passages with ground-truth overlays teach that "confident but
  wrong" is the failure mode to look for.
- 🛠️ [**prompt-forge**](./prompt-forge/) — Iteratively refine prompts to hit a
  target output. A deterministic mock-LLM scores rubric hits so it works fully
  offline; optional BYO-key mode compares mock vs. real model output side by
  side.

### Ages 5–13 (any track)

- 🤖 [**ai-learner**](./ai-learner/) — How AI works, for kids ages 5–13. Three
  age tracks (🌱 Sprouts 5–7, 🔍 Explorers 8–10, 🔧 Builders 11–13), each with
  hands-on lessons on training from examples, features, bias, weights, prompts,
  and hallucinations. Built around **predict-then-reveal** interactions.

### For parents

- 💬 [**conversation-spark**](./conversation-spark/) — Curated bank of ~300
  conversation starters ranked by age, mood, and recency — for when "How was
  school?" keeps getting "fine".

---

## Shared design philosophy

All projects here follow the same principle: a kid clicking the right answer
isn't proof of understanding. Each app is designed so the activities themselves
generate evidence of comprehension — through multi-representation, prediction,
failure-mode reasoning, or application to new cases — and surfaces that
evidence in a parent dashboard where relevant.

Single-file HTML, no build, no dependencies, no backend, no required API keys.
Just open in a browser.
