What is clustering?

Clustering means grouping things that are similar — but similar in what way? That depends on which features you measure!

A computer doing k-means picks k starting points (centroids), then repeats:

  1. Each point joins the nearest centroid
  2. Each centroid moves to the middle of its group
  3. Repeat until nobody moves!
Try the same dataset with different axes — same creatures, but the clusters change. That's the AI lesson: what you measure shapes what you see!
